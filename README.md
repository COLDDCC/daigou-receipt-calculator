# 代购费用核算 · 小票生成

单文件网页小工具：填写商品明细、折扣、汇率和通讯费后自动核算总价，并生成一张可下载/复制的小票图片。

## 使用

直接用浏览器打开 `index.html` 即可，无需构建或安装依赖。

## 功能

- 多行商品明细（品名 / 日元单价 / 数量），可任意增删
- 折扣、汇率、尾数处理（保留分 / 进位到角 / 进位到元）
- 通讯费按件数平摊，支持日元或人民币
- 客户、日期、单号、备注等单据信息
- Canvas 绘制小票样式，一键下载 PNG 或复制到剪贴板

## 两张表的用法

出个人费用清单要两张表，顺序不能反：

1. **登记表**（下单前）：谁要了哪本、原价、商品链接。粘到「从表格导入」。
   带「客户」列时会自动按客户拆成一批，链接末段会被记成品番。
2. **结算表**（骏河屋实际订单）：品番 / 商品タイトル / 単価 / 数量 / 金額。
   粘到「二次核算」。

以登记表的「谁要了什么」为准，钱一律按结算表重算：

- 金额取结算表的 **「金額」列**，骏河屋已经把该行折扣扣掉、并进位到整数日元了。
  所以不打折的商品也能算对，不会被统一乘一次折扣。
- 登记表里有、结算表里没有的商品 = **没买到**，标成「未购入」列在小票上，
  不计金额、不计件数、也不计入本次总点数（平摊分母）。
- 品番优先精确匹配，登记表的链接末段（`185185606`）能对上结算表的
  `185185606001`；对不上才退回按品名匹配。同一品番要了两本时，
  结算表的两行会各算一次。
- 结算表的「枝番」列会被 Excel 转成日期（`1-1` → `1月1日`），这一列按文本读、
  完全不参与匹配和排序。

核对结果和没对上的品番会同时写进页面提示和浏览器控制台。

## 注意

通讯费和运费是每批现算的金额，**不会**记到下一批；汇率、折扣、尾数处理才会记住。
